2. POPULATE THE AGENT DATA VOLUME

   On first start the init container copies default agent files from the
   image onto the Longhorn PVC. To replace them with your own files:

   # Find the agent pod name
   kubectl -n {{ .Values.namespace }} get pods -l app=rockbot-agent

   # Copy your local agent directory to the PVC
   kubectl -n {{ .Values.namespace }} cp \
     src/RockBot.Agent/agent/ <pod-name>:/data/agent/

   # Copy your mcp.json
   kubectl -n {{ .Values.namespace }} cp \
     src/RockBot.Agent/mcp.json <pod-name>:/data/agent/mcp.json

   Or exec in and edit directly:
   kubectl -n {{ .Values.namespace }} exec -it deploy/{{ include "rockbot.fullname" . }}-agent -- /bin/sh


3. ACCESS THE BLAZOR UI

   The Blazor UI is exposed on your Tailscale network via the
   Tailscale Kubernetes Operator at:
{{- if .Values.blazor.tailscale.ingress.enabled }}

     https://{{ .Values.blazor.tailscale.hostname }}.<your-tailnet>.ts.net

   The exact name appears in the ADDRESS field once the certificate is
   issued (Let's Encrypt, provisioned by the operator — allow a minute):

     kubectl -n {{ .Values.namespace }} get ingress {{ include "rockbot.fullname" . }}-blazor

   Still private to your tailnet — Funnel is not enabled.
{{- else }}

     http://{{ .Values.blazor.tailscale.hostname }}

   It may take 30–60 s after the service is created for the Tailscale
   device to register. Check operator status with:

     kubectl -n {{ .Values.namespace }} describe svc {{ include "rockbot.fullname" . }}-blazor

   For HTTPS, set blazor.tailscale.ingress.enabled=true — read the
   switchover note in values.yaml first, the device is replaced.
{{- end }}
{{- if .Values.agui.enabled }}


   ACCESS THE AG-UI API

{{- if (default dict .Values.agui.auth).enabled }}
   The AG-UI proxy (docs/agui.md) is in app mode: every request needs an
   OIDC token (Authorization: Bearer) from an account on agui.auth's
   allowlist. The pod needs outbound HTTPS to the token issuer.
{{- else }}
   The AG-UI proxy (docs/agui.md) asks nobody who they are: whoever can
   reach it can talk to the agent. Set agui.auth.enabled for app auth.
{{- end }}
{{- if .Values.agui.ingress.enabled }}

     https://{{ .Values.agui.ingress.host }}/agui
{{- if not (default dict .Values.agui.auth).enabled }}

   You set agui.ingress.allowUnauthenticated=true: make sure whatever sits
   in front of this ingress really does authenticate every request.
{{- end }}
{{- else if .Values.agui.tailscale.ingress.enabled }}

     https://{{ .Values.agui.tailscale.hostname }}.<your-tailnet>.ts.net/agui

   Private to your tailnet. The exact name appears in the ADDRESS field:

     kubectl -n {{ .Values.namespace }} get ingress {{ include "rockbot.fullname" . }}-agui
{{- else }}

     http://{{ .Values.agui.tailscale.hostname }}/agui

   Private to your tailnet. Check it with:

     curl http://{{ .Values.agui.tailscale.hostname }}/healthz
